## Master Glossary

| Term | One-Line Definition |
|------|-------------------|
| AI | Machines performing tasks requiring human intelligence |
| ML | Machines learning from data |
| Deep Learning | Neural networks with many layers |
| Generative AI | ML application that creates new content |
| Foundation Model | Large model trained on massive unlabeled data |
| LLM | Foundation model for human language |
| Labeled data | Data with associated tags/categories |
| Unlabeled data | Raw, unprocessed, untagged data |
| Supervised learning | Learning from labeled data |
| Unsupervised learning | Finding patterns in unlabeled data |
| Reinforcement learning | Learning through reward/penalty interaction |
| Hallucination | AI generating convincing but false information |
| Knowledge cutoff | Date after which model has no training data |
| Bias | Training data imbalances amplified in outputs |
| Grounding | Connecting AI output to verifiable sources |
| RAG | Retrieve → Augment → Generate |
| Fine-tuning | Retraining a model for a specific domain |
| Temperature | Controls randomness/creativity of outputs |
| Context window | Amount of text model can consider at once |
| HITL | Human reviews/validates ML outputs |
| Gemini | Google's multimodal AI model |
| Imagen | Google's text-to-image model |
| Veo | Google's text/image-to-video model |
| Gemma | Lightweight, open Google model for local deployment |
| Gemini Enterprise Agent Platform | Google Cloud's unified ML platform |
| Gemini Enterprise | Internal knowledge AI agents for employees |
| CCaaS | Contact Center as a Service |
| SAIF | Secure AI Framework |
| Explainable AI | Making AI decisions transparent and understandable |
| Responsible AI | Ethical, harm-free AI throughout the lifecycle |
| Zero-shot | Prompting with no examples |
| Few-shot | Prompting with multiple examples |
| CoT | Chain-of-thought: reasoning through intermediate steps |
| ReAct | Reason and act: agents reasoning and taking action |
